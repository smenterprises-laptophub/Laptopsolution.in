Free GitHub Pages publishing
1. Create a new PUBLIC repository on GitHub, for example laptop-solution-kothrud.
2. Upload index.html to the repository root (top level) and commit the changes.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose branch main and folder /(root), then Save.
6. Wait for deployment; open the URL shown in Settings > Pages. It will typically look like https://YOUR-USERNAME.github.io/laptop-solution-kothrud/

GitHub Free requires a public repository for Pages. Anything in the published website is public. Publishing may take several minutes. Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
